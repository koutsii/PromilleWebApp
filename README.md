# Promillelaskuri

Kevyt full-stack-verkkosovellus veren alkoholipitoisuuden (promillemäärän) ja arvioidun palamisajan laskentaan Widmarkin kaavalla.

## Teknologiat
* **Backend:** C++20
* **Tietokanta:** SQLite3
* **Frontend:** ReactJS

## Ominaisuudet
* Promillemäärän, puhtaan alkoholin (g) ja palamisajan laskenta
* Pikavalinnat yleisimmille juomille
* Laskentahistorian tallennus ja haku paikallisesta SQLite-tietokannasta
